手机 ATX 安装/连接指南

适用场景

在线设备列表看不到手机 / 无法运行 UI 自动化时，通常需要先开启开发者选项与 USB 调试，并在手机上安装并启动 atx-agent。

1) 打开开发者选项与 USB 调试

  • 设置 → 关于手机 → 连续点击“版本号”7 次，开启“开发者选项”。
  • 设置 → 开发者选项 → 打开“USB 调试”。
  • （建议）同时打开“USB 调试（安全设置）/ 通过 USB 安装/ 允许模拟点击”等相关权限（不同品牌名称略有差异）。

2) 连接电脑并确认 ADB 可识别

  • 使用数据线连接后，手机上弹出的授权提示选择“允许 USB 调试”。
  • 在电脑执行：adb devices，应能看到设备序列号与状态 device。
  • 如显示 unauthorized：手机端撤销 USB 调试授权后重新插拔并再次允许。

3) 安装并启动 atx-agent（常用方式）

确保电脑已安装 Python 与相关工具后，执行以下命令之一（按你的环境选择）：

python -m pip install -U uiautomator2 python -m uiautomator2 init
  • 初始化成功后，手机会安装并启动 atx-agent（后台服务）。
  • 如公司环境限制外网，请配置镜像或离线安装（需运维/开发提供安装包与源）。

4) 验证 atx-agent 是否可用

  • 执行：adb shell ps | findstr atx（Windows）或 adb shell ps | grep atx（macOS/Linux）
  • 也可执行：adb forward tcp:7912 tcp:7912 后访问 http://127.0.0.1:7912（若你的版本启用 web 服务）。

常见问题

  • 设备反复掉线：更换数据线/USB 口，关闭省电策略，避免 USB 仅充电模式。
  • 权限弹窗卡住：确保手机端允许“通过 USB 安装/调试”，并解锁屏幕后再执行 init。
  • 多设备：建议一次只连一台排查，确认稳定后再批量接入。
