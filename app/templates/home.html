Android UI 自动化测试平台

一站式 Android UI 自动化测试与脚本录制平台

本平台集成设备管理、用例管理、任务执行、报告查看与脚本录制能力， 帮助你快速构建、维护与执行 Android UI 自动化测试。

进入自动化测试页 进入脚本录制页

主要功能概览

  • 设备管理

    自动发现在线 Android 设备，查看设备信息，选择设备进行测试或录制。

  • 用例管理与执行

    图形化管理测试用例，在线编辑 Python 脚本，一键下发到设备执行并生成测试报告。

  • 执行集与任务调度

    支持将多个用例组合成执行集，批量执行并汇总报告，方便回归与套件管理。

  • 脚本录制

    实时预览设备屏幕，通过鼠标点击录制操作，自动生成可编辑的 Python 测试脚本。

快速上手

1. 连接设备

确保 Android 设备已通过 ADB 连接到本机，并在平台的“在线设备”列表中显示为在线状态。

2. 编写或录制用例

可以在“自动化测试页”中手动编辑 Python 用例，也可以在“脚本录制页”通过操作设备自动生成用例。

3. 执行并查看报告

选择用例或执行集，启动任务执行，执行完成后可在平台内查看详细的 Allure 报告与执行历史。
